# 🏭 СОСТОЯНИЕ ПРОЕКТА: ДЕНЬ 1 (Save Point)
**Дата:** 2026-10-07
**Цель:** Автономный контент-завод для 18 сайтов-спутников + основной сайт 103vet.by.
**KPI:** 500-600 страниц за <2 часов, 0 правок от программиста.

## ✅ ЧТО УЖЕ СОЗДАНО И В GIT:
1. `AGENTS_REGISTRY.json` — Полный реестр 33+ агентов с контрактами (вход/выход).
2. `master_factory.py` — Базовый оркестратор конвейера (6 этапов + параллельный аудит 12 агентов).
3. `agents/` — Папка с восстановленными скриптами (writer_v2_2, chief_editor_v1_1, domain_expert_critic_v2_1, linker_ai_v5, url_seo_specialist, auditor_*, deploy_agent и др.).
4. `fix_*.py` — 17 патчей для автоматического исправления ошибок.
5. `starter.html` и `styles.css` — Базовые шаблоны для тестирования.

## 🚫 ЖЕСТКИЕ ПРАВИЛА (НЕ НАРУШАТЬ):
1. **НИКАКИХ ДОГАДОК:** Если AI не помнит начало чата, он НЕ должен гадать. Он должен просить пользователя проверить Git или прочитать `AGENTS_REGISTRY.json`.
2. **GIT FIRST:** Любой новый код сначала коммитится и пушится в `vera103vet/aio-factory`, и только потом тестируется.
3. **НЕТ РУЧНОЙ ВЕРСТКЕ В ЧАТЕ:** AI не генерирует HTML вручную в диалоге. Вся генерация идет только через `master_factory.py`.
4. **ПРИНЦИП "НУЛЬ ПРАВОК":** Страница не попадает в деплой, пока не получит статус `APPROVED` от `auditor_head` (минимум 10/12 аудиторов).

## 🚀 КАК ВОЗОБНОВИТЬ РАБОТУ (Инструкция для AI):
Если контекст потерян, пользователь пишет: "Загрузи состояние из PROJECT_STATE_DAY_1.md и AGENTS_REGISTRY.json". AI должен немедленно признать это и действовать строго по этим файлам.
